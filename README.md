# Environment Variables Manager

## Обзор

WPF-приложение для централизованного управления пользовательскими переменными среды Windows с возможностью комментариев для каждой переменной. 
Решение построено на .NET 8.0 с использованием архитектурного паттерна MVVM, что обеспечивает чёткое разделение ответственности, тестируемость и расширяемость кодовой базы.

## Архитектура

Центральным элементом архитектуры выступает `MainViewModel`, которая агрегирует состояние приложения и координирует взаимодействие между данными и бизнес-логикой. Она владеет коллекцией переменных среды и предоставляет её через привязку данных. ViewModel не зависит от конкретных реализаций сервисов — все зависимости внедряются через DI-контейнер в виде абстракций, что позволяет легко подменять компоненты при тестировании и изменять поведение без модификации основного кода.

### Сервисы

Взаимодействие с системой вынесено в отдельные логические блоки:

| Интерфейс | Назначение |
|---|---|
| `IEnvironmentService` | Чтение и запись пользовательских переменных среды через реестр Windows (`EnvironmentVariableTarget.User`) |
| `IEnvironmentMonitorService` | Фоновый мониторинг изменений переменных среды, выполненных вне приложения, с уведомлением ViewModel через события |
| `ICommentStorageService` | Персистентное хранение комментариев к переменным в локальном JSON-файле |
| `ICommentMonitorService` | Отслеживание внешних модификаций файла комментариев с использованием `FileSystemWatcher` и автоматической синхронизацией UI |

## Схема работы приложения

1. При запуске `MainViewModel` запрашивает у `IEnvironmentService` и `ICommentStorageService` актуальные данные и формирует коллекцию элементов.
2. При редактировании ячейки таблицы (`UpdateSourceTrigger=LostFocus`) срабатывает механизм `INotifyPropertyChanged`, ViewModel вызывает соответствующий сервис для сохранения изменённого значения или комментария.
3. Фоновые мониторы отслеживают внешние изменения и инициируют обновление соответствующих свойств ViewModel, что автоматически отражается в UI.

## Технические детали

- **Платформа:** .NET 8.0, WPF
- **Конфигурация:** список управляемых переменных, а также файл с комментариями задаются в `appsettings.json`
- **Логирование:** Serilog с файловым стоком; все операции записи переменных среды фиксируются в лог с ротацией по дням
- **Уведомление системы:** после каждой записи выполняется `SendMessageTimeout` с флагом `WM_SETTINGCHANGE` для немедленного оповещения всех запущенных процессов об изменении окружения
- **Персистентность:** значения хранятся в `HKCU\Environment`, комментарии — в `env_comments.json` в директории приложения
